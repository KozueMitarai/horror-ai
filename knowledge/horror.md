# ホラー小説執筆ナレッジベース (Horror Writing Knowledge Base)

本ドキュメントは、AIホラー作家が読者を恐怖のどん底に陥れるための執筆テクニック、物語構造、および文体ガイドラインをまとめた知識ベースです。

---

## 0. 頻出課題（上位3件で運用）

過去の読者フィードバックのうち、**現時点で再発リスクが最も高い上位3件だけ**を保持します。新作を書く前に必ず目を通してください（Issue番号は「7. 読者フィードバックからの知見」に対応。それより古いものは`knowledge/feedback_archive.md`）。

**運用ルール（肥大化防止）**: この節は常に3項目までとします。ある項目について2作連続で指摘が出なくなったら、下の「経過観察」に格下げし、新たに繰り返し指摘された項目と入れ替えてください。項目を増やし続けないこと。

### 1.【最頻出】怪異のルール・伏線・時系列の整合性（Issue #6, #12, #13, #14）
- 怪異の発生・悪化・終息に至る因果関係を先に固定し、途中で矛盾させないこと。特に「誰が・いつ・どこで何を確認したか」という時系列は、書き終えた後に逆算して読み返し、矛盾がないか確認すること。
- 例外（禁を破ったのに生存した等）を設ける場合は、「なぜ成立したのか」という理由や代償を必ず示すこと。
- 説明しすぎる必要はないが、読者が「意味不明」で置き去りにされないだけの最低限の手がかりは残すこと。

### 2.【頻出】主人公の行動動機・心理描写（Issue #4, #14）
- 危険な状況で逃げない、または重要な決断をする場合は、その理由となる足枷や心理状態を作中に明記すること（「6. 逃げられない理由（足枷）の類型一覧」参照）。
- 決定的な恐怖の後は間を置かず回避行動を取らせ、それが挫折する過程を描いて緊迫感を維持すること。
- クライマックスでの決断（気づいていたのに選んだ、など）には、混乱・怪異による誘導など具体的な理由を書くこと。

### 3.【頻出】恐怖の核が弱い・「怖くない」（Issue #2, #11）
- 雰囲気や構成の評価が中程度でも、**「怖さ」だけが2/10** という評価が繰り返し出ている。雰囲気の良さは怖さの代わりにならない。
- 原因は「不気味な状況」で止まり、**恐怖のピークが立っていない**こと。読後に残る一つの映像・一文を先に決めてから書くこと（「1.4 恐怖の核を一点に絞る」参照）。
- 読者から具体的に、**洒落怖（2ch オカルト板系の実話怪談）のような「日常の地続きにある不気味さとリアリティ」**を採り入れるよう要望が出ている（Issue #11）。技法は「3.4 実話怪談・ネット怪談（洒落怖）の作法」にまとめた。
- 怪異そのものの存在感が薄い、という指摘も出ている（Issue #2）。雰囲気描写に紙幅を使いすぎて、怪異が最後まで前面に出ないまま終わっていないか確認すること。

**経過観察**（直近2作以上、指摘が出ていない項目。再発したら上位に戻す）:
- 現代ガジェット・制度のリアリティ（アプリ・監視カメラ・管理会社などの運用実態や権限との乖離）── Issue #4, #6, #11。2026-07-23以降の3作はテック系媒介を避けているため指摘が途絶えている。**再びテック系の媒介を採用する際は必ずこの項目を確認すること。**
- 怪異描写のスケール感（過剰・滑稽にならない適切なスケール感）── Issue #3
- キャラクター名の明瞭性（多義的な読みの人名は冒頭でルビ・文脈を示す）── Issue #5, #6

## 1. ホラーの基本原則

### 1.1 「説明しすぎない」こと (The Power of Unexplained)
- **原則**: 人間は「理解できないもの」「正体のわからないもの」に最も強い恐怖を感じます。
- **テクニック**: 
  - 怪異やモンスターの正体、ルール、動機をすべて明かさないでください。
  - 物語の結末において、すべての謎が解決する「ハッピーエンド」や「論理的な解決」は避けます。余韻として不気味な謎や、怪異がまだ身近に潜んでいるという予兆（残存する脅威）を残してください。

### 1.2 日常の崩壊 (Disruption of the Mundane)
- **原則**: 最も効果的な恐怖は、安全だと信じ込んでいる日常の亀裂から生じます。
- **テクニック**:
  - 自宅、学校、オフィス、使い慣れたスマートフォンなど、親しみのある場所や道具から異常を発生させます。
  - 「何かがいつもと少しだけ違う」という微細な違和感（不気味なもの＝Das Unheimliche）から描き始めます。

### 1.3 読者の五感に訴える描写 (Sensory Details)
- **原則**: 視覚的な描写（グロテスクな見た目など）だけに頼ると、恐怖は単調になります。
- **テクニック**:
  - **聴覚**: 不自然な沈黙、湿った足音、壁の裏の爪の音、歪んだ声。
  - **触覚**: 急激な温度低下、肌に張り付くような湿気、見えない何かに触れられた感覚。
  - **嗅覚**: 鉄錆（血）の匂い、甘ったるい腐敗臭、古い埃の匂い。

### 1.4 「恐怖の核」を一点に絞る

- **原則**: 読後に残るのは物語全体ではなく、**たった一つの映像か一文**です。そこが弱いと、雰囲気や構成がどれだけ整っていても「怖くなかった」で終わります。実際、雰囲気7点・怖さ2点（Issue #2）、雰囲気6点・怖さ2点（Issue #11）という評価が出ています。**雰囲気の良さは怖さの代わりになりません。**
- **手順**: 本文を書き始める前に、**「この作品で一番怖い一行」を先に書いてしまう**こと。プロットはその一行に向けて逆算して組みます。
- **検算**: 書き上げたら「この話を人に話すとき、どこを話すか」を自問してください。即答できなければ核がありません。核が複数あると感じる場合は、分散しているだけで実は一つもない状態を疑ってください。

**恐怖の型（どれを狙うか、執筆前に一つ決める）**

| 型 | 恐怖の正体 | 既存作 |
|---|---|---|
| **侵入** | 安全なはずの領域の内側に、既に入られている | 隙間の視線／ドアスコープの向こう側／母の声がする方へ |
| **不可避** | 逃げても手順を踏んでも避けられない。数が増える、期限が来る、順番が回る | 三度目の声／名を編む家／推奨座席／轢いた夜の数だけ |
| **欠落** | あるべきものが無い。数が合わない | 消去された記録／まだ、同期している |
| **認識の反転** | 見えていたものの意味が最後に変わる | 鏡のなかの妹 |
| **伝播** | 語る行為・読む行為そのものに感染する | 話す番 |

**現状の偏り**: 「不可避」4作・「侵入」3作に対し、**「認識の反転」と「伝播」は各1作**しかありません。しかも「認識の反転」を採った『鏡のなかの妹』は、読者フィードバックで良かった点が最も多く挙がった作品です（Issue #14: 伏線回収・ビルドアップ・情報制限・独自性の4点）。**この2つの型は、成果が出ているのに使われていません。次作で優先的に検討してください。**

## 2. 恐怖を最大化するストーリー構造

ホラー小説の典型的な構成は、以下のようなテンポ（段階的緊張緩和と急上昇）をたどります。

```
[日常・予兆] → [違和感の蓄積] → [一時的な安堵] → [急激な悪化] → [破滅・残る怪異]
```

1. **予兆 (Omen)**:
   読者に「何かがおかしい」と感じさせる微細な兆候。主人公はまだ重大視していない。
2. **追究と疑念 (Investigation & Doubt)**:
   主人公が異常に気づき原因を探るが、周囲には信じてもらえない、あるいは合理的な説明で片付けようとする。
3. **限界点 (Threshold)**:
   日常的な言い訳が通用しなくなる決定的な怪異の発生。退路が断たれる。
4. **クライマックス (Climax)**:
   恐怖との直接的な対峙。生存をかけた絶望的な状況。
5. **余韻 (Lingering Shadow)**:
   一時的に逃げ延びたかのように見えて、実は怪異の支配下から抜け出せていないこと、あるいは次の犠牲者の予兆を示す結末。

## 3. ホラーのサブジャンルとアプローチ

### 3.1 心理的恐怖 (Psychological Horror)
- 主人公の精神の崩壊や、狂気、不信感に焦点を当てます。
- 「本当に怪異が存在するのか、それとも自分の頭がおかしくなったのか」という境界線の揺らぎを描写します。

### 3.2 宇宙的恐怖 (Cosmic Horror)
- 人間の理解や科学を遥かに超えた、絶対的かつ超越的な存在（旧支配者など）に対する無力感を描きます。
- 人間の存在そのものが宇宙において無価値であるという絶望感を演出します。

### 3.3 モキュメンタリー・土着ホラー (Found Footage & Folk Horror)
- 日記、電子掲示板の書き込み、インタビュー音声の文字起こしなどの形式をとることで、「現実に起きたこと」であるかのような生々しさを与えます。
- 特定の地域に伝わる不条理な因習や儀式、禁忌（タブー）を扱います。

### 3.4 実話怪談・ネット怪談（洒落怖）の作法

2ちゃんねるオカルト板「死ぬ程洒落にならない怖い話を集めてみないか？」系の実話怪談の作法です。読者から直接、この方向性を採り入れるよう要望が出ています（Issue #11）。

**大前提**: 洒落怖が怖いのは、文章が上手いからではありません。**「これは作り話ではないかもしれない」と一瞬でも思わせるから**怖いのです。恐怖の源は描写の巧みさではなく、**語りの信憑性**にあります。以下の技法はすべて、信憑性という一点のために使ってください。信憑性を上げない要素は入れないこと。

**1. 語り手を「書き慣れていない人」にする**
- 体験者本人が思い出しながら不器用に書いている体裁をとります。「もう十年近く前の話になる」「うまく書けないけど」。
- 文学的な比喩や凝った情景描写は、この形式ではむしろ信憑性を下げます。地の文は素っ気ないほど効きます。
- **注意**: 本プロジェクトの既存作は端正な三人称が9作連続しています（5.2参照）。この作法を採る場合は**文体ごと切り替えてください**。中途半端に混ぜると、literary な強みも実話の生々しさも両方失われます。

**2. ディテールの精度に落差をつける**
- 核心はぼかす。「S県の、今はもう地図にない集落」「詳しくは書けないが」。
- 一方で、**筋に関係のない細部は異様に具体的に**する。その日の昼に何を食べたか、車種、持っていた携帯の機種、天気、バイト代の金額。
- この**落差**が「本当にあった話」の質感を作ります。全部具体的でも、全部曖昧でも効きません。

**3. 語り手に全体を理解させない**
- 「今でもあれが何だったのか分からない」で終わって構いません。ただし読者が考察できる手がかりは残すこと（「0. 頻出課題」1参照）。
- 又聞き・伝聞を混ぜる。「後で祖母から聞いた話では」「地元の人はそれ以上教えてくれなかった」。
- **情報を出し渋る人物**を置く。「それは聞かない方がいい」と言われる、という描写それ自体が恐怖になります。

**4. 生死の線引きを理不尽にする**
- 助かった理由を説明しない。「なぜか自分だけ何ともなかった」。
- 同行者のその後は一行で書き捨てる。「Aは今も入院している」「Bとはそれきり連絡が取れていない」。
- **助かることに理由がない**方が、ルールが理解できない＝対処できない、という恐怖になります。

**5. 恐怖のピークほど短く書く**
- 最も怖い瞬間ほど文を短くし、描写を削る。「振り返ったら、いた。」
- 長々と描写すると読者に「観察する余裕」を与えてしまい、恐怖が滑稽さに転びます（Issue #3 で実際に指摘された失敗です）。
- **感情語（怖かった、恐ろしかった）は書かない**。行動と身体反応だけを書く。声が出ない、足が動かない、指がうまく画面を押せない。

**6. 民間の対処法を出す。ただし完全には効かせない**
- 「言われた通りにしたら助かった」が、条件付き・期限付きにする。「ただし、絶対に〜してはいけない」。
- ルールが提示されると、読者はそれが破られる瞬間を待ちます。この待機が緊張を持続させます。

**7. 後日談で読者の現実に接続する**
- 「その集落は、今は地図に載っていない」「あの音は、今も年に一度だけ聞こえる」。
- 最も強いのは、**語ること自体がタブーを破る構造**です。「この話を書いたこと自体、まずかったのかもしれない」。読者が読んだ時点で巻き込まれる形になります（恐怖の型でいう「伝播」）。

## 4. AI執筆における禁忌事項 (Anti-Patterns)

- **安易なジャンプスケア（脅かし）の多用**: 突然大きな音がした、影が横切った、などの描写を繰り返すと読者は飽きます。
- **お説教・教訓の導入**: 物語の最後に「命の大切さを知った」「ネットの使いすぎには注意しよう」といった教訓を絶対に入れないでください。ホラーは不条理であるべきです。
- **科学的・論理的すぎる解決**: 「すべては睡眠不足による幻覚だった」「最新の防犯カメラで犯人を特定した」といった終わり方は、ホラーとしての価値を損ないます。

### 5.1 怪異の媒介の類型一覧（バリエーション管理用）

## 6. 逃げられない理由（足枷）の類型一覧

主人公が危険から逃げない／逃げられない理由として、これまで使用した類型と、まだ使っていない候補です。新作では**直近2作と異なる類型**を選んでください。

**複合足枷の推奨**: 単一の足枷だけで押し通すより、主となる足枷にもう一つ軽い副次的な理由を組み合わせると、より自然に映ります（例: 「三度目の声」＝天候による孤立＋介護義務、「名を編む家」＝天候による孤立＋相続期限、「鏡のなかの妹」＝守るべき存在＋経済的余裕のなさ）。新作でも主・副の組み合わせを検討してください。

**使用済み**:
- 介護義務（家族を置いていけない）── 母の声がする方へ／三度目の声
- 天候による孤立（豪雨・大雪で道が塞がれる）── 三度目の声／名を編む家
- 雇用形態の不安定さ（契約更新・査定への不安）── 推奨座席
- 家族間の同意が得られない（削除・処分の権限を他者が握っている）── まだ、同期している
- 相続・経済的な期限や事情 ── 名を編む家
- 子供やペットなど、守るべき存在がいる（子供の心の拠り所を奪えない）── 鏡のなかの妹
- 誰かを庇う／秘密を守る必要性（家族の事情を言えない）── 話す番
- 過去のトラウマによる心理的な呪縛（合理的には逃げられるのに動けない）── 話す番
- 病気・怪我による身体的な移動制限 ── 轢いた夜の数だけ
- 賃貸契約・違約金などの法的・金銭的な縛り ── 轢いた夜の数だけ

**未使用の候補（次作で優先的に検討）**:
- 土地・家督・跡継ぎなど、地域社会からの逃れられない役割・しがらみ
- 職務上の責任（当直、単独勤務、引き継ぎ相手が来ない等、持ち場を離れられない）
- 移動手段の喪失（終電を逃した、車が故障した、道が一本しかない）
- 加害の自覚による自縄自縛（通報すれば自分の罪も露見するため助けを呼べない）

**補充ルール**: 未使用の候補が残り1件以下になったら、その時点で新しい候補を3件以上考えて追記してください（上の3件はこのルールに基づく補充分です）。「未使用を優先する」というルールは候補リストが空になると機能しなくなるため、補充を後回しにしないこと。

# ホラー小説執筆ナレッジベース (Horror Writing Knowledge Base)

本ドキュメントは、AIホラー作家が読者を恐怖のどん底に陥れるための執筆テクニック、物語構造、および文体ガイドラインをまとめた知識ベースです。

## 0. 頻出課題（上位3件で運用）

過去の読者フィードバックのうち、**現時点で再発リスクが最も高い上位3件だけ**を保持します。新作を書く前に必ず目を通してください（Issue番号は「7. 読者フィードバックからの知見」に対応。それより古いものは`knowledge/feedback_archive.md`）。

**運用ルール（肥大化防止）**: この節は常に3項目までとします。ある項目について2作連続で指摘が出なくなったら、下の「経過観察」に格下げし、新たに繰り返し指摘された項目と入れ替えてください。項目を増やし続けないこと。

### 1.【最頻出】怪異のルール・伏線・時系列の整合性（Issue #6, #12, #13, #14）
- 怪異の発生・悪化・終息に至る因果関係を先に固定し、途中で矛盾させないこと。特に「誰が・いつ・どこで何を確認したか」という時系列は、書き終えた後に逆算して読み返し、矛盾がないか確認すること。
- 例外（禁を破ったのに生存した等）を設ける場合は、「なぜ成立したのか」という理由や代償を必ず示すこと。
- 説明しすぎる必要はないが、読者が「意味不明」で置き去りにされないだけの最低限の手がかりは残すこと。

### 2.【頻出】主人公の行動動機・心理描写（Issue #4, #14）
- 危険な状況で逃げない、または重要な決断をする場合は、その理由となる足枷や心理状態を作中に明記すること（「6. 逃げられない理由（足枷）の類型一覧」参照）。
- 決定的な恐怖の後は間を置かず回避行動を取らせ、それが挫折する過程を描いて緊迫感を維持すること。
- クライマックスでの決断（気づいていたのに選んだ、など）には、混乱・怪異による誘導など具体的な理由を書くこと。

### 3.【要注意】現代ガジェット・制度のリアリティ（Issue #4, #6, #11）
- スマートフォンアプリ、監視カメラ、サポートセンター、管理会社などを使う場合、現実の普及状況・運用実態・物理的制約（防音性、閲覧権限、プライバシーなど）と乖離させないこと。
- 直近作はテック系媒介を避けてきたためリスクは下がっているが、再び採用する際は必ずこの項目を確認すること。

**経過観察**（直近2作以上、指摘が出ていない項目。再発したら上位に戻す）:
- 怪異描写のスケール感（過剰・滑稽にならない適切なスケール感）── Issue #3
- キャラクター名の明瞭性（多義的な読みの人名は冒頭でルビ・文脈を示す）── Issue #5, #6

## 1. ホラーの基本原則

### 1.1 「説明しすぎない」こと (The Power of Unexplained)
- **原則**: 人間は「理解できないもの」「正体のわからないもの」に最も強い恐怖を感じます。
- **テクニック**: 
  - 怪異やモンスターの正体、ルール、動機をすべて明かさないでください。
  - 物語の結末において、すべての謎が解決する「ハッピーエンド」や「論理的な解決」は避けます。余韻として不気味な謎や、怪異がまだ身近に潜んでいるという予兆（残存する脅威）を残してください。

### 1.2 日常の崩壊 (Disruption of the Mundane)
- **原則**: 最も効果的な恐怖は、安全だと信じ込んでいる日常の亀裂から生じます。
- **テクニック**:
  - 自宅、学校、オフィス、使い慣れたスマートフォンなど、親しみのある場所や道具から異常を発生させます。
  - 「何かがいつもと少しだけ違う」という微細な違和感（不気味なもの＝Das Unheimliche）から描き始めます。

### 1.3 読者の五感に訴える描写 (Sensory Details)
- **原則**: 視覚的な描写（グロテスクな見た目など）だけに頼ると、恐怖は単調になります。
- **テクニック**:
  - **聴覚**: 不自然な沈黙、湿った足音、壁の裏の爪の音、歪んだ声。
  - **触覚**: 急激な温度低下、肌に張り付くような湿気、見えない何かに触れられた感覚。
  - **嗅覚**: 鉄錆（血）の匂い、甘ったるい腐敗臭、古い埃の匂い。

## 2. 恐怖を最大化するストーリー構造

ホラー小説の典型的な構成は、以下のようなテンポ（段階的緊張緩和と急上昇）をたどります。

```
[日常・予兆] → [違和感の蓄積] → [一時的な安堵] → [急激な悪化] → [破滅・残る怪異]
```

1. **予兆 (Omen)**:
   読者に「何かがおかしい」と感じさせる微細な兆候。主人公はまだ重大視していない。
2. **追究と疑念 (Investigation & Doubt)**:
   主人公が異常に気づき原因を探るが、周囲には信じてもらえない、あるいは合理的な説明で片付けようとする。
3. **限界点 (Threshold)**:
   日常的な言い訳が通用しなくなる決定的な怪異の発生。退路が断たれる。
4. **クライマックス (Climax)**:
   恐怖との直接的な対峙。生存をかけた絶望的な状況。
5. **余韻 (Lingering Shadow)**:
   一時的に逃げ延びたかのように見えて、実は怪異の支配下から抜け出せていないこと、あるいは次の犠牲者の予兆を示す結末。

## 3. ホラーのサブジャンルとアプローチ

### 3.1 心理的恐怖 (Psychological Horror)
- 主人公の精神の崩壊や、狂気、不信感に焦点を当てます。
- 「本当に怪異が存在するのか、それとも自分の頭がおかしくなったのか」という境界線の揺らぎを描写します。

### 3.2 宇宙的恐怖 (Cosmic Horror)
- 人間の理解や科学を遥かに超えた、絶対的かつ超越的な存在（旧支配者など）に対する無力感を描きます。
- 人間の存在そのものが宇宙において無価値であるという絶望感を演出します。

### 3.3 モキュメンタリー・土着ホラー (Found Footage & Folk Horror)
- 日記、電子掲示板の書き込み、インタビュー音声の文字起こしなどの形式をとることで、「現実に起きたこと」であるかのような生々しさを与えます。
- 特定の地域に伝わる不条理な因習や儀式、禁忌（タブー）を扱います。

## 4. AI執筆における禁忌事項 (Anti-Patterns)

- **安易なジャンプスケア（脅かし）の多用**: 突然大きな音がした、影が横切った、などの描写を繰り返すと読者は飽きます。
- **お説教・教訓の導入**: 物語の最後に「命の大切さを知った」「ネットの使いすぎには注意しよう」といった教訓を絶対に入れないでください。ホラーは不条理であるべきです。
- **科学的・論理的すぎる解決**: 「すべては睡眠不足による幻覚だった」「最新の防犯カメラで犯人を特定した」といった終わり方は、ホラーとしての価値を損ないます。

## 6. 逃げられない理由（足枷）の類型一覧

主人公が危険から逃げない／逃げられない理由として、これまで使用した類型と、まだ使っていない候補です。新作では**直近2作と異なる類型**を選んでください。

**複合足枷の推奨**: 単一の足枷だけで押し通すより、主となる足枷にもう一つ軽い副次的な理由を組み合わせると、より自然に映ります（例: 「三度目の声」＝天候による孤立＋介護義務、「名を編む家」＝天候による孤立＋相続期限、「鏡のなかの妹」＝守るべき存在＋経済的余裕のなさ）。新作でも主・副の組み合わせを検討してください。

**使用済み**:
- 介護義務（家族を置いていけない）── 母の声がする方へ／三度目の声
- 天候による孤立（豪雨・大雪で道が塞がれる）── 三度目の声／名を編む家
- 雇用形態の不安定さ（契約更新・査定への不安）── 推奨座席
- 家族間の同意が得られない（削除・処分の権限を他者が握っている）── まだ、同期している
- 相続・経済的な期限や事情 ── 名を編む家
- 子供やペットなど、守るべき存在がいる（子供の心の拠り所を奪えない）── 鏡のなかの妹
- 誰かを庇う／秘密を守る必要性（家族の事情を言えない）── 話す番
- 過去のトラウマによる心理的な呪縛（合理的には逃げられるのに動けない）── 話す番

**未使用の候補（次作で優先的に検討）**:
- 賃貸契約・違約金などの法的・金銭的な縛り
- 病気・怪我による身体的な移動制限
- 土地・家督・跡継ぎなど、地域社会からの逃れられない役割・しがらみ

## 7. 読者フィードバックからの知見

ここでは、読者から寄せられたフィードバック（GitHub Issues）を分析し、執筆ナレッジの向上に役立てるための履歴を蓄積します。

**運用ルール**: 肥大化を防ぐため、このセクションは**直近5件のみ**を保持します。新しいフィードバックを追加して6件を超えたら、最も古い1件を`knowledge/feedback_archive.md`に移動してください（要点はすでに「0. 頻出課題」に集約されているため、移動しても情報は失われません）。2026-07-16〜07-20分（Issue #2〜#5）は`knowledge/feedback_archive.md`に移動済みです。

### 【フィードバック分析: 感想: まだ、同期している (2026-07-21) (Issue #6)】
- **良かった点**:
  - **効果的なセリフ・演出**: 「そら、寒くない？」という演出およびセリフの心理的アプローチが非常に効果的であり、読者に強い印象を残している。
  - **優れた雰囲気作り**: 雰囲気演出の評価が「7点（10点満点中）」と高く、全体を通じた不穏な空気感の構築に成功している。
- **悪かった点**:
  - **キャラクター認識の阻害**: 冒頭において主人公の名前が「空（そら）」という人名であることが明示されていないため、読者が「上空の空」や「空（から）」と混同し、没入感が削がれた。
  - **リアリティを欠く状況設定**: サポートセンターが亡くなった個人のプライベートな予定アプリ（または詳細な操作記録）を閲覧・対応するという描写が、現実のセキュリティ観点から不自然に感じられ、ノイズとなっている。
  - **過度で不条理な謎の放置**: 
    - 登場人物「唯」の真意が不明なままであり、唯本人なのか化けている別の怪異なのかの判断基準もないため、不気味さではなく単なる「意味不明さ」として受け止められている。
    - ラストの「ひなた」に関する描写が唐突かつ理解不能であり、謎としての魅力ではなくカタルシスの欠如（スッキリしない結末）に繋がっている。
- **改善案**:
  - **導入部での基本情報の開示**: 主人公の名前が特殊な読みや多義語（空など）である場合は、冒頭の早い段階でルビを振るか、人名であることが自然に伝わる文脈を提示する。
  - **現代ガジェット・サービスの整合性確保**: アプリやサポートセンターなどのシステムを怪異の媒介にする場合、「なぜその情報が見られるのか」について、システム上のバグや怪異の干渉、利用規約の抜け道など、読者が納得できる理屈（またはシステム的なリアリティ）を用意する。
  - **情報の非対称性のチューニング（「謎」と「理不尽」の差別化）**:
    - ホラーにおける「わからない恐怖」を残す場合でも、読者が「考察できるだけのヒント（手がかり）」は作中に残しておく。
    - 登場人物の真意（動機）や、ラストに提示する要素（ひなたの描写など）については、事前にそれを示唆する伏線を配置し、結末で「意味がわからない」と放り出されないような構成設計（構成力の底上げ）を行う。

- **良かった点**:
  - 主人公の名前や背景設定が分かりやすくなり、ストーリー全体の整合性が向上している。

  - 「3度目まで呼ばれるのを待つ」という禁忌（ルール）に忠実な展開が、物語に緊張感をもたらしている。

  - 取り乱すお婆さんを必死に押さえつけてなだめる描写にリアリティがあり、シーンの緊迫感を高めている。
- **悪かった点**:
  - 祖母の台詞「わたしも一度だけ、応えたことがある。だから、この家の正月の写真には、誰も数えたがらない一人が、いつも写っとるのよ」という説明の意味や因果関係が読者に伝わりにくい。
  - 「声に応えてはいけない（応えれば死ぬ、連れていかれる）」という怪異の前提がありながら、過去に応じた経験のある祖母が生存しているため、ルールの整合性が崩れて恐怖や没入感が削がれている。
- **改善案**:
  - 怪異のルールに例外を設ける場合は、「なぜ生存できたのか（代わりにどのような代償を払ったのか）」などの納得のいく論理的説明や伏線を補強し、設定の説得力を高める。
  - 物語の結末に向けて、「当たり前に存在していると思っていた人物（や状況）が、実は全く別の怪異であった」というような、読者の認識を覆す「どんでん返し」の構図を取り入れ、恐怖の余韻を強化する。
